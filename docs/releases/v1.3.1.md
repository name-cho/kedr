# Kedr 1.3.1: улучшения веб-предпросмотра

Обновление для Windows x64, Kedr Studio и Kedr Python.

- В **Web Preview** можно открыть HTTP- или HTTPS-адрес уже запущенного dev-сервера кнопкой **Open URL**. Сам сервер нужно запустить отдельно.
- Предпросмотр обновляется при создании, удалении, перемещении и переименовании файлов проекта, а также при изменении содержимого.
- Исправлено открытие файлов, в именах которых есть `+` или `%`.
- Локальный сервер не отдаёт файлы через символические ссылки, ведущие за пределы проекта, и освобождает поток при остановке.

Предпросмотр не собирает и не транспилирует проект. Emmet для CSS и конфигурация запуска dev-сервера пока не реализованы.

Для обоих продуктов доступны установщик и портативная сборка; для Kedr Python также архив исходников. Контрольные суммы приложены к релизу. Сборки не подписаны, поэтому Windows SmartScreen может показать предупреждение. Перед установкой проверьте источник и контрольную сумму.
