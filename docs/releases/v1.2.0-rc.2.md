# Kedr 1.2 RC2: сборка целиком в CI

Второй кандидат в релиз на IntelliJ Platform **2026.3 RC (263.7307)**. Главное отличие от RC1: оба продукта собраны в GitHub Actions от начала до конца, без ручной сборки на рабочей машине. Windows x64.

## Что изменилось после RC1

- Сборка, проверка и публикация идут одним конвейером. Релиз появляется только если оба продукта собрались, прошли проверку артефактов и smoke-тест.
- Smoke-тест проверяет не только портативную сборку, но и установку: тихая установка, список плагинов из установленной копии, тихое удаление.
- Установщик и портативная сборка каждого продукта проходят проверку до публикации: контрольные суммы, идентичность продукта, файлы запуска, обязательные плагины, отсутствие рекламных модулей коммерческих редакций.
- Архив исходников Kedr Python теперь публикуется с контрольными суммами `.sha256` и `.sha512`.
- В релизе есть общие файлы `SHA256SUMS` и `SHA512SUMS` для всех файлов.
- Kedr Python проверяется на наличие Go-плагина так же строго, как Studio: он входит в комплект обоих продуктов.

## Kedr Studio

Универсальный редактор для исходного кода, конфигураций и текстовых файлов: Java, Kotlin, Python, Go, web-языки и другие форматы.

- Подсветка синтаксиса `.go` через TextMate работает без `gopls`.
- Если `gopls` установлен и доступен через `PATH`, подключаются дополнение кода, диагностика, переходы к определениям и форматирование.
- В мастере нового проекта есть Go: он создаёт `go.mod` и `main.go`.
- Python-плагин входит в комплект.

## Kedr Python

Отдельная IDE для профессиональной разработки на Python: интерпретаторы и окружения, дополнение кода, навигация, рефакторинги, отладка и тесты.

- В комплект входит интеграция mypy. Сам mypy должен быть установлен в выбранном Python-окружении.
- Доступны инструменты анализа и форматирования кода из открытого Python-плагина.
- Отладчик использует классический pydevd. Закрытый DAP-модуль JetBrains не входит в сборку.

## Общее для обоих продуктов

- Нет предложений перейти на коммерческие редакции JetBrains и нет рекламных модулей этих редакций. Сторонние плагины Marketplace сохраняют свои условия лицензирования.
- Отчёты об ошибках, сбоях запуска и использовании памяти сохраняются локально в ZIP. Kedr не отправляет их в JetBrains.
- Русский языковой пакет включён.
- Коды продуктов `IC`/`PC` и имена `idea64.exe`/`pycharm64.exe` сохранены для совместимости с плагинами.

## Файлы

Для каждого продукта: установщик `.exe` и портативная сборка `.win.zip`. Kedr Python дополнительно получает архив исходников `-sources.zip`. Рядом с каждым файлом лежат `.sha256` и `.sha512`.

Проверка всех файлов сразу:

```powershell
Get-Content SHA256SUMS | ForEach-Object {
  $expected, $file = $_ -split '\s+', 2
  $actual = (Get-FileHash -Algorithm SHA256 -LiteralPath $file.TrimStart('*')).Hash.ToLower()
  if ($actual -ne $expected) { throw "Checksum mismatch: $file" }
}
```

## Перед установкой

Это кандидат в релиз на базе IntelliJ Platform 2026.3 RC. Сборки не подписаны, поэтому Windows SmartScreen может показать предупреждение. Проверьте контрольную сумму и источник файла перед запуском.

Закройте предыдущую копию продукта перед обновлением. Установщик работает без прав администратора. Для портативной сборки распакуйте ZIP в пустую папку и запустите файл из `bin`.

Сборка только для x64. ARM64 в этом релизе не собирается.

Ошибки и предложения: https://github.com/name-cho/kedr/issues
