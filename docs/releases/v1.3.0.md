# Kedr 1.3: веб-разработка

Релиз на IntelliJ Platform **2026.3 (263.7307)**, собран и проверен в GitHub Actions. Windows x64.

## Что нового после 1.2

### Языки веба — это отдельные языки

- Свои типы файлов и иконки платформы: CSS, SCSS, Less, JavaScript, JSX, TypeScript, TSX.
- Иконки берутся из самой платформы, поэтому совпадают с остальными и имеют вариант для тёмной темы.
- `.mjs` и `.cjs` относятся к JavaScript, `.mts` и `.cts` — к TypeScript.
- HTML остаётся полноценным языком платформы: дополнение тегов и атрибутов, форматирование, структура файла, инспекции и быстрые исправления.

### Подсветка синтаксиса

- Работает сразу, без установки плагинов и без Node.js.
- Грамматики HTML, CSS, SCSS, Less, JavaScript и JSX уже входят в платформу.
- В комплекте полная грамматика TypeScript и TSX, а не только ключевые слова.

### Новый проект для веба

- В мастере нового проекта появился вариант **Web**.
- Создаются `index.html`, `styles/main.css`, `scripts/main.js`, `README.md` и `.gitignore`.
- Страница уже подключает стили и скрипт, поэтому предпросмотр работает сразу после создания проекта.

### Предпросмотр страниц

- Новое окно инструментов **Web Preview** показывает страницу рядом с редактором.
- Проект отдаётся по HTTP с локального адреса `127.0.0.1`, поэтому относительные пути, ES-модули и `fetch` работают как на настоящем сервере.
- Страница перезагружается через 200 мс после сохранения файла, в том числе если файл изменила другая программа.
- Кнопка **Open in Browser** открывает ту же страницу во внешнем браузере.
- Пункт **Open in Web Preview** есть в меню Tools и в контекстном меню редактора.
- Сервер слушает только петлевой адрес и останавливается вместе с проектом.

### Установщик

- Windows связывает `.html`, `.htm`, `.css`, `.scss`, `.less`, `.js`, `.jsx`, `.ts` и `.tsx` с Kedr Studio.
- Плагин входит в комплект обоих продуктов.

## Чего нет

- Дополнение кода, рефакторинги, инспекции и отладка для CSS, JavaScript и TypeScript живут в закрытых плагинах JetBrains для платных продуктов и не собираются из этого дерева. Если у вас есть лицензия, эти плагины можно поставить из Marketplace.
- Emmet для CSS и запуск сервера разработки из IDE пока не сделаны. Проекту со сборкой нужен собственный сервер: запустите его и нажмите **Open in Browser**.
- Предпросмотр не транспилирует и не собирает файлы.

## Kedr Studio

Универсальный редактор для исходного кода, конфигураций и текстовых файлов: Java, Kotlin, Python, Go, веб-языки и другие форматы. Python-плагин входит в комплект.

## Kedr Python

Отдельная IDE для профессиональной разработки на Python: интерпретаторы и окружения, дополнение кода, навигация, рефакторинги, отладка и тесты. Веб-плагин и предпросмотр страниц входят в комплект, поэтому шаблоны и статические страницы проекта можно смотреть в IDE.

- В комплект входит интеграция mypy. Сам mypy должен быть установлен в выбранном Python-окружении.
- Отладчик использует классический pydevd. Закрытый DAP-модуль JetBrains не входит в сборку.

## Общее для обоих продуктов

- Нет предложений перейти на коммерческие редакции JetBrains и нет рекламных модулей этих редакций.
- Отчёты об ошибках, сбоях запуска и использовании памяти сохраняются локально в ZIP.
- Русский языковой пакет включён.
- Коды продуктов `IC`/`PC` и имена `idea64.exe`/`pycharm64.exe` сохранены для совместимости с плагинами.

## Файлы

Для каждого продукта: установщик `.exe` и портативная сборка `.win.zip`. Kedr Python дополнительно получает архив исходников `-sources.zip`. Рядом с каждым файлом лежат `.sha256` и `.sha512`, в релизе есть общие `SHA256SUMS` и `SHA512SUMS`.

Проверка всех файлов сразу:

```powershell
Get-Content SHA256SUMS | ForEach-Object {
  $expected, $file = $_ -split '\s+', 2
  $actual = (Get-FileHash -Algorithm SHA256 -LiteralPath $file.TrimStart('*')).Hash.ToLower()
  if ($actual -ne $expected) { throw "Checksum mismatch: $file" }
}
```

## Перед установкой

Сборки не подписаны, поэтому Windows SmartScreen может показать предупреждение. Проверьте контрольную сумму и источник файла перед запуском.

Закройте предыдущую копию продукта перед обновлением. Установщик работает без прав администратора. Для портативной сборки распакуйте ZIP в пустую папку и запустите файл из `bin`.

Сборка только для x64.

Ошибки и предложения: https://github.com/name-cho/kedr/issues
