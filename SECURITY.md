# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities in Kedr privately through GitHub Security Advisories:

https://github.com/name-cho/kedr/security/advisories/new

If that form is unavailable, contact the maintainer through https://github.com/name-cho and ask for a private channel. Do not open a public issue for an unpatched vulnerability.

Include the product and build number, Windows version, reproduction steps, and the impact you observed. A minimal proof of concept is helpful. Please give us a reasonable chance to investigate and ship a fix before public disclosure.

## Scope

This policy covers Kedr Studio, Kedr Python, their installers, and the release workflows in this repository. Kedr is built from IntelliJ Platform and PyCharm open-source code; third-party components keep their own licenses and support channels. If you believe an issue belongs to an upstream component rather than a Kedr modification, say so in the report and we will help route it.

## Expectations

Kedr is a small open-source project. We do not operate a bug bounty program and cannot promise a fixed response time. We will acknowledge reports when we can, keep you informed during investigation, and credit reporters in release notes unless they prefer otherwise.
